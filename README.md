# Four Card Feature Section

A responsive web component showcasing four feature cards in an elegant grid layout.

## Features

- **Responsive Design**: Adapts seamlessly to desktop, tablet, and mobile screens
- **CSS Grid Layout**: Modern layout with strategically offset cards on desktop
- **Semantic HTML5**: Accessible and SEO-friendly markup
- **Custom Styling**: Each card features a unique colored top border
- **Embedded SVG Icons**: Optimized graphics for each feature
- **Modern Typography**: Google Fonts integration with Poppins font family

## The Four Features

1. **Supervisor** (Cyan) - Monitors activity to identify project roadblocks
2. **Team Builder** (Red) - Scans our talent network to create the optimal team for your project
3. **Karma** (Orange) - Regularly evaluates our talent to ensure quality
4. **Calculator** (Blue) - Uses data from past projects to provide better delivery estimates

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Google Fonts (Poppins)
- SVG Graphics

## Viewing the Project

Simply open `index.html` in a web browser or serve it with any HTTP server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx http-server

# Using PHP
php -S localhost:8000
```

Then navigate to `http://localhost:8000` in your browser.

## Responsive Breakpoints

- **Mobile**: < 640px (single column)
- **Tablet**: 641px - 1024px (2x2 grid)
- **Desktop**: > 1025px (3-column offset grid)
